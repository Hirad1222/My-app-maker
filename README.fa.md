# AutoRoute VPN — نسخهٔ اولیهٔ پروژه

این پروژه یک کلاینت بومی اندروید برای فایل‌های پیکربندی **WireGuard** است. از کتابخانهٔ رسمی WireGuard Tunnel استفاده می‌کند و پس از تأیید مجوز VPN توسط اندروید، می‌تواند تونل واقعی را بالا بیاورد.

## وضعیت فعلی

- رابط فارسی و راست‌چین
- واردکردن فایل `.conf` از طریق انتخاب‌گر فایل اندروید
- اعتبارسنجی اولیهٔ پیکربندی WireGuard
- درخواست مجوز سیستمی VPN
- اتصال و قطع اتصال با WireGuard Tunnel Library
- اندازه‌گیری زمان پاسخ HTTPS پس از اتصال (این معیار ICMP ping نیست)
- هیچ IP یا سرور ساختگی داخل پروژه قرار داده نشده است

## محدودیت‌های صادقانهٔ این نسخه

این یک نسخهٔ اولیهٔ قابل توسعه است، نه سرویس VPN رایگان با سرورهای آماده. برای اتصال به اینترنت باید فایل WireGuard معتبر از سروری داشته باشی که اجازهٔ استفاده از آن را داری. کلید خصوصی و تنظیمات همتا باید متعلق به همان سرویس باشند.

دکمهٔ «بررسی سرورها» فعلاً سرورها را به‌صورت خودکار تعویض نمی‌کند. انتخاب خودکار ایمن باید هر پیکربندی را جداگانه برقرار کند، از داخل تونل به مقصد آزمایشی درخواست بفرستد، نتیجه را ثبت کند و سپس بهترین اتصال را دوباره برقرار کند. این بخش عمداً به‌عنوان قابلیت تکمیل‌نشده معرفی شده و نتیجهٔ ساختگی تولید نمی‌کند.

## ساخت APK

1. پوشه را در Android Studio باز کن.
2. از JDK 17 استفاده کن.
3. اجازه بده Gradle وابستگی‌ها را از Google Maven و Maven Central دریافت کند.
4. ابتدا `Sync Project with Gradle Files` را اجرا کن.
5. سپس از منوی **Build → Build APK(s)** استفاده کن.
6. فایل Debug APK معمولاً در `app/build/outputs/apk/debug/` ساخته می‌شود.

برای APK انتشار، از **Build → Generate Signed Bundle / APK** استفاده کن و کلید امضای خودت را نگه‌دار.

## عیب‌یابی

- اگر Gradle خطای نسخه داد، نسخهٔ Android Studio و Gradle JDK را بررسی کن.
- اگر اتصال برقرار نشد، اعتبار فایل `.conf`، Endpoint، پورت UDP، کلیدها و وضعیت سرور را بررسی کن.
- اتصال WireGuard موفق به‌تنهایی تضمین نمی‌کند که DNS، IPv6 یا تمام مسیرهای اینترنت درست کار می‌کنند؛ این موارد باید روی دستگاه واقعی آزمایش شوند.

## فهرست IP و افزودن دستی

در صفحهٔ اصلی می‌توان IP یا دامنه را دستی به فهرست آدرس‌های هدف اضافه کرد. این ورودی به‌تنهایی یک تونل VPN ایجاد نمی‌کند؛ برای اتصال WireGuard همچنان فایل کامل `.conf` شامل کلیدها، آدرس تونل، Endpoint و تنظیمات همتا لازم است.

برای پشتیبانی از بیش از ۱۰٬۰۰۰ مورد، روش درست واردکردن یک فهرست بزرگ از منابع مجاز و مستند است؛ نه پیمایش تصادفی تمام IPv4. تعداد IPها با تعداد سرورهای VPN فعال و قابل‌استفاده برابر نیست.
